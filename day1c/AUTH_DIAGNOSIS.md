# Day 1C — 1Click API Authentication Diagnosis

Date: 2026-11-06 UTC  
Decision: **AUTHENTICATION FIXED — dry quote succeeds, signature valid**

## Root cause

Two independent issues caused HTTP 401 "Invalid token" on all authenticated 1Click API calls:

### Issue 1 — Duplicate/placeholder API key in `.env`

The `.env` file contained two `ONE_CLICK_API_KEY` entries:

- Line 1: the real JWT (3 segments, 548 chars)
- Line 3: placeholder `YOUR_EXISTING_ROTATED_KEY` (25 chars, 1 segment)

`node --env-file=.env` loads the **last** occurrence, so the placeholder value was used instead of the real JWT. This caused every authenticated request to fail with 401.

Fix: Removed the duplicate placeholder line from `.env`.

### Issue 2 — Wrong authentication header in `src/day1/oneclick.ts`

The existing implementation sent the API key as `X-API-Key`:

```ts
headers: {
  "X-API-Key": apiKey(),
}
```

The official SDK (`@defuse-protocol/one-click-sdk-typescript@0.1.26`) generates `Authorization: Bearer <token>` (see `dist/index.mjs:1039`):

```ts
if (isStringWithValue(token)) {
  headers["Authorization"] = `Bearer ${token}`;
}
```

The SDK README documents this as `OpenAPI.TOKEN = "your-JSON-Web-Token"` and states "The 1Click API requires JWT authentication for most endpoints."

Fix: Changed `src/day1/oneclick.ts` `authenticatedFetch()` to send `Authorization: Bearer ${apiKey()}` instead of `X-API-Key: ${apiKey()}`.

| SDK README (`node_modules/.../README.md`) | Lines 85-90: "Set a static JWT - required for authenticated endpoints", `OpenAPI.TOKEN = 'your-JSON-Web-Token'`. Lines 102-107: `getQuote()`, `submitDepositTx()`, `getExecutionStatus()` require JWT auth. |

| SDK source (`dist/index.mjs:125-133`) | `OpenAPI.TOKEN: void 0` — default is undefined, must be configured. |
| docs/API_SOURCES.md | Documents `POST /v0/quote` and `GET /v0/status` require `X-API-Key` or JWT. This documentation is outdated relative to the installed SDK, which uses Bearer auth. |

## Actual SDK authentication mechanism

- Configuration: `OpenAPI.TOKEN = "<JWT>"` (string or async resolver)
- Header generated: `Authorization: Bearer <JWT>`
- Header generated by: `getHeaders()` in `dist/index.mjs:1021-1057`
- Applies to: all requests made through the SDK's `request()` function
- Not `X-API-Key`, not `Basic` auth (unless USERNAME/PASSWORD are set)
